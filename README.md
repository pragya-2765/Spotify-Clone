# 🎵 Spotify Clone — Web Music Player  
*A front-end project developed in December 2024*

This project is a simple and visually appealing **Spotify Clone** built using **HTML, CSS, and JavaScript**. It recreates the basic UI and interaction elements of Spotify, including playlists, music player controls, and responsive layout.

## 🚀 Features
- Modern Spotify-style UI  
- Music player with play/pause controls  
- Playlist and navigation sections  
- Local music file support  
- Responsive design  
- Clean and modular code structure  

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)  
- Custom images and assets

## 📦 How to Run
1. Clone or download the repository  
2. Open `index.html` in any browser  
3. Enjoy the music player UI 🎶
